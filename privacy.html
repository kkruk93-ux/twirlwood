Privacy policy

Effective date: 20 November 2026 (version 1.2.0)

Twirlwood is a 3D fairy-tale platformer that runs in your browser or as an installed app. This policy describes what the game does — and does not — do with information.

No data collection

The game does not collect personal information. It does not use an analytics SDK, advertising SDK, crash reporter, or account system. It does not send gameplay, device identifiers, or contact details to a server operated by the game.

Information stored only on your device

Level progress (unlocked levels, stars, best times, coins, star gems and lives), your chosen hero, and graphics, sound, music, vibration, screen-shake and control preferences are saved in your browser’s local storage on this device so you can continue later. This information stays on the device. You can clear it with Reset progress in Settings, or by clearing the site or app data. The game does not back this information up to a cloud account.

Network use

The first visit may download the game files. After that, a service worker can run the game offline. Links on the About screen (YouTube, X, and Suno) and this policy’s outbound links go to those third-party sites, which have their own policies. The game does not set those links to track you.

Ads and purchases

This version of Twirlwood does not show ads and does not offer in-app purchases. The source code includes unused placeholder hooks for possible future ads or purchases. Those hooks do not run any ad or billing SDK today and do not collect data.

Children

The game is a simple platformer suitable for a general audience. Because it does not collect personal data, it does not request information from children.

Changes

If this policy changes, the updated text will be posted at this address with a new effective date.

Contact

For questions about this policy, use the public channels listed in the game’s About screen: YouTube, X, or Suno.
